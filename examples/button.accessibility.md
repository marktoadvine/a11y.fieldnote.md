# action\-button — accessibility fieldnotes

Contextual notes and open questions; not verification results or a conformance claim.

<a id="note-native-control"></a>

## native\-control

**Topic:** semantics

**Statement:** Use a native button for actions\.

<a id="note-visible-label"></a>

## visible\-label

**Statement:** Give the button visible text that describes the action\.

**Additional context:**

```yaml
owner: content designer
```

<a id="note-text-resize"></a>

## text\-resize

**Topic:** visual

**Statement:** Let the label wrap and the button grow when text is enlarged\.

<a id="note-disabled-behavior"></a>

## disabled\-behavior

**Topic:** interaction

**Question:** Should an unavailable action remain discoverable, and how will its reason be explained?

<a id="note-focus-contrast"></a>

## focus\-contrast

**Topic:** focus

**Question:** Is the focus indicator distinguishable on every surface where this button is used?
